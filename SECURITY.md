# Security Policy

## Supported versions

Security fixes are applied to the current default branch.

## Reporting a vulnerability

Please do not publish exploitable vulnerability details in a public issue. Use GitHub's private vulnerability reporting feature for this repository if it is enabled, or email [abdullahzulfiqar137@gmail.com](mailto:abdullahzulfiqar137@gmail.com) with the repository name, affected path or component, impact, and safe reproduction steps.

Do not include real passwords, access tokens, personal data, or other secrets in a report.

## Scope

This repository is a public portfolio website. Do not submit spam, social-engineering attempts, or denial-of-service tests against the live site.
